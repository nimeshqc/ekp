# Nova Search — Product Overview

Nova Search is Atlas Industries' internal knowledge retrieval platform. It lets any team ask natural-language questions over their own document collections and receive grounded, cited answers.

## Architecture

Nova indexes documents into 384-dimensional embeddings generated by an in-house model served on CPU, and stores vectors in PostgreSQL with the pgvector extension. Retrieval uses HNSW approximate nearest-neighbour search with a configurable similarity threshold. No document content is ever sent to an external embedding API.

## Grounded answering

Answers are generated by an external LLM constrained to the retrieved passages. Nova refuses to answer when retrieval confidence falls below the configured threshold, guaranteeing grounded answers instead of hallucinations. Every sentence in an answer is traceable to a highlighted source passage.

## Deployment

Nova runs on a single virtual machine with two CPU cores and four gigabytes of memory. The stack consists of an nginx reverse proxy, a Python API server, and a PostgreSQL database. Documents are processed entirely on-platform: parsing, chunking, embedding and indexing all happen locally, and only the final answer generation calls an external language model.
